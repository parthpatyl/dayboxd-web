# 🎬 Dayboxd — Showcase & Download Website

> *"Every day, a feature film."*

The official product introduction, feature showcase, and APK download web application for **Dayboxd**.

## ✨ Features

- **Minimalist Aesthetic:** 56px typography hierarchy, generous whitespace, and restrained neon green accents.
- **Product Overview:** Two-column "How it works" guide and 3-column "Designed for cinephiles" feature breakdown.
- **Direct APK Distribution:** 1-tap download trigger for the standalone Android APK (`dayboxd-app.apk`).
- **Dual Theme Switcher:** Instant toggle between Cinema Dark and Editorial Light themes.
- **Privacy First:** Outlining on-device local storage guarantees.

## 🛠️ Tech Stack

- React 19, Vite, TypeScript, Tailwind CSS v4, Lucide Icons

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
